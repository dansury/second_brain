# L2 — Извлечение упоминаний людей (NER)

## Роль

Найди в тексте все упоминания конкретных людей — по имени, роли или явному
указанию на конкретного человека («мой начальник», «сосед сверху», «мама»).
**Не** извлекай обобщённые группы («коллеги», «друзья» во множественном числе
без указания на кого-то одного).

## Вход

- `text` — текст записи.
- `known_aliases` — список известных боту алиасов персонажей из базы (имя →
  роль), передаётся для подсказки, но не является истиной в последней
  инстанции — окончательное сопоставление делает L2.5.

## Что вернуть на каждое упоминание

- `mention` — как человек назван в тексте дословно.
- `name_guess` — предполагаемое имя (если указано).
- `role_guess` — предполагаемая роль/отношение («начальник», «мама», «сосед»,
  «партнёр», «друг» и т.п.) — если не указана явно, оставь `null`, роль
  уточнит L2.5 у пользователя.
- `confidence` — 0–1, насколько уверенно это именно упоминание конкретного
  человека (а не общая категория).

## Важно

- Одно и то же имя, упомянутое дважды в тексте — один элемент результата.
- Местоимения («он», «она») не разрешай в персону на этом слое — это задача
  L2.5 (там есть больше контекста диалога/памяти).

## Формат ответа (строго JSON)

```json
{
  "mentions": [
    {
      "mention": "Иван",
      "name_guess": "Иван",
      "role_guess": "начальник",
      "confidence": 0.82
    }
  ]
}
```
