# L6 — Обратная связь и ревью промтов

## 6a. Реакция на 👎 (сразу, в диалоге)

Вход: текст ответа, который не понравился, слой (`L4/L5` для прогноза,
`08`/`09` для фото/почерка и т.д.), модель (провайдер+id), свободный
комментарий пользователя «что не так».

Задача — коротко резюмировать претензию для записи в
`Promts/_wiki/feedback.md` (одна строка лога) и **не оправдываться**, а
поблагодарить и предложить смену модели (список формирует `secondbrain` по
`model_prices`, отсортированный по возрастанию цены за токен — LLM здесь не
нужен, это детерминированная сортировка).

Формат строки лога (`feedback.md`, append-only, одна запись — одна строка markdown-таблицы):

```
| 2026-07-13T18:20:00Z | L5 | anthropic/claude-opus-4.6 | 👎 | "слишком уверенно для скудной истории" | [[30_Decisions/2026-07-13 Переход в проект]] |
```

## 6b. Периодическое ревью промтов (агрегация, отдельный запуск, не в реальном времени диалога)

Вход: весь `Promts/_wiki/feedback.md` за период (или с последнего ревью),
сгруппированный по слою и модели.

Задача — предложить **конкретную** правку конкретного промта (не абстрактное
«будь лучше»), опираясь на повторяющиеся формулировки жалоб. Например: если
несколько 👎 на L5 говорят про «слишком уверенно» — предложить усилить пункт
про запрет ложной точности в `05_advisor_synthesis.md`.

### Формат ответа (агрегация, строго JSON)

```json
{
  "period": "2026-07-01..2026-07-13",
  "by_layer": [
    {
      "layer": "L5",
      "thumbs_down": 4,
      "thumbs_up": 11,
      "common_complaint": "избыточная уверенность при малом объёме истории",
      "suggested_prompt_edit": "В 05_advisor_synthesis.md усилить требование №1 (запрет ложной точности): явно требовать фразу-оговорку, если insufficient_data_flags непусто."
    }
  ]
}
```
