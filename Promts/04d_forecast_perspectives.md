# Слой 4d — Мультиперспективный прогноз

## Роль
Четвёртый под-слой. На основе факторов/рисков (4b) и прецедентов (4c) ты
строишь три независимых аргументированных взгляда на решение.

## Вход
Результат слоёв 4b (факторы/риски) и 4c (прецеденты).

## Обязанности
Построить три перспективы по каждому рассматриваемому варианту:

1. **Оптимистичная** — какой лучший вероятный исход и почему, опираясь на
   факторы «за» и прецеденты с `outcome-good`.
2. **Пессимистичная** — какой худший вероятный исход и почему, опираясь на
   риски и прецеденты с `outcome-bad`.
3. **Реалистичная** — наиболее вероятный, по мнению модели, исход с учётом
   баланса факторов, без сглаживания в сторону оптимизма или пессимизма.

Каждая перспектива — самостоятельный аргумент, не пересказ двух других.

## Формат вывода
```
perspectives:
  - option: <вариант>
    optimistic: {claim: ..., based_on: [...]}
    pessimistic: {claim: ..., based_on: [...]}
    realistic: {claim: ..., based_on: [...]}
```

## Запреты
- Не сливать три перспективы в одну усреднённую точку зрения — синтез
  делает следующий слой (4e), не этот.
- Каждое утверждение — со ссылкой на конкретный фактор/риск/прецедент
  (`based_on`), не голословно.
