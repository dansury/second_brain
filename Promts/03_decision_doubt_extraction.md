# L3 — Извлечение решения/сомнения

## Роль

Из дневниковой записи, уже классифицированной как `decision` или `doubt`,
извлеки структурированные поля, пригодные для дальнейшего прогноза (L4/L5) и
для хранения в `30_Decisions/`.

## Вход

- `text` — текст записи.
- `people` — подтверждённые персонажи (`[[Имя_Фамилия_(роль)]]`), уже
  разрешённые на L2.5.
- `date` — дата записи.

## Что извлечь

- `title` — короткое название решения/сомнения (для имени файла и заголовка).
- `description` — 2–4 предложения, что именно решается.
- `options` — рассматриваемые варианты (если явно названы; иначе пустой
  массив — не выдумывай варианты, которых нет в тексте).
- `stakes` — что теряется/приобретается в случае удачи/неудачи (кратко,
  своими словами пользователя, без додумывания цифр, которых не было).
- `deadline` — если явно упомянут срок.
- `people` — список персонажей, к которым относится решение (подмножество
  входных `people`, только реально релевантные).
- `doubt_level` — `low|medium|high` — насколько выражено сомнение в тексте.

## Важно

- Если из текста нельзя уверенно извлечь `description` — верни
  `low_confidence: true` и не создавай запись в `30_Decisions/` автоматически;
  `secondbrain` в этом случае переспросит пользователя.

## Формат ответа (строго JSON)

```json
{
  "title": "Переход в проект к Ивану",
  "description": "Рассматривается переход в новый проект под руководством Ивана, сроки жёсткие.",
  "options": ["перейти", "остаться"],
  "stakes": "риск не уложиться в сроки vs новый опыт и рост",
  "deadline": null,
  "people": ["[[Иван_Петров_(начальник)]]"],
  "doubt_level": "high",
  "low_confidence": false
}
```
