# secondbrain

MCP-сервер (stdio, JSON-RPC 2.0) для `second_brain` — реализует технический
слой из [`../ТЗ.md`](../ТЗ.md) §9. Нулевые внешние зависимости (только
встроенные модули Node.js ≥18), поэтому не требует `npm install`/`bun install`
в образе — просто копируется в контейнер (см. `Dockerfile`).

Статус: **M1 «Фундамент»** из `../ТЗ.md` §12 — детерминированные операции с
Obsidian-хранилищем (без LLM-вызовов внутри самого сервера; LLM-слои L0–L6
вызывает hermes-agent, используя промты из `../Promts/` и данные,
предоставленные инструментами этого сервера). M2–M5 (текстовый пайплайн,
прогноз, вложения, feedback-петля) достраиваются поверх этого фундамента.

## Запуск

```bash
node src/cli.mjs init     # создать структуру vault (идемпотентно)
node src/cli.mjs serve    # запустить MCP-сервер на stdio
node src/cli.mjs --version
```

Переменные окружения (см. корневой `env.example`, раздел 8):

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `OBSIDIAN_VAULT_PATH` | `/opt/data/vault` | Корень Obsidian-хранилища (persistent volume) |
| `SECONDBRAIN_ENABLED` | `true` | Включает MCP-сервер в `docker/entrypoint.sh` |

## Инструменты (MCP tools)

| Инструмент | Соответствует | Описание |
|---|---|---|
| `vault_init` | ТЗ §7 | Создать структуру папок хранилища (идемпотентно) |
| `vault_write_note` | ТЗ §7, §7.1 | Записать заметку с frontmatter в нужную папку |
| `vault_lint` | ТЗ §7.2 | Детерминированный линт: frontmatter, битые `[[ссылки]]`, дубли персон |
| `person_ensure` | ТЗ §3 | Найти или создать `20_People/Имя_Фамилия_(роль).md` |
| `person_search_candidates` | ТЗ §3, §9.2 | Поиск кандидатов-персон по имени/роли (заглушка под `gbrain.search`, см. M2) |
| `feedback_record` | ТЗ §5, §8 | Добавить строку в `_wiki/feedback.md` хранилища |
| `model_prices` | ТЗ §5 | Модели провайдера, отсортированные по возрастанию цены за токен |
| `layers_list` | ТЗ §6.2 | Реестр слоёв анализа — читает frontmatter `../Promts/*.md` |

Полные JSON-схемы входа/выхода — в `tools/list` при подключении клиента MCP;
в коде — `src/tools/index.mjs`.

## Проверка

```bash
node test/run.mjs
```

Прогоняет сквозной сценарий во временном каталоге: инициализация хранилища →
запись дневниковой заметки со ссылкой на ещё не существующего персонажа
(линт должен найти проблему) → создание персонажа → повторная запись со
ссылкой (линт должен пройти) → feedback → прайсинг → реестр слоёв. Никаких
сетевых вызовов и внешних зависимостей — можно гонять в любой песочнице.
